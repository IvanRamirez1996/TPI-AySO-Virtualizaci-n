## 📋 Descripción del Proyecto
Este proyecto documenta la implementación práctica de conceptos de virtualización de hardware mediante el uso del hipervisor de tipo 2 **Oracle VirtualBox**. 

Como caso práctico, se llevó a cabo el despliegue de una máquina virtual con **Ubuntu Server (64-bit)**, configurando un adaptador de red en **modo Puente (Bridge)** para la integración transparente a la red local, y la posterior instalación y puesta en marcha de un servidor web **Apache**. Asimismo, se implementaron políticas de respaldo mediante **snapshots** (instantáneas) del estado funcional del sistema.
